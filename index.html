Padrões Internos (fixos)
LINKPLAS
REGEX
Ref: P{REF} · Qtd: Q000{QTY}000
Exemplo: P4901974V000 Q000010000 → Ref 4901974V000 · Qtd 10
TUTIPLAST/NORPLAST
QR · ;
Separador ; · Ref: campo 4 (índice 3) · Qtd: último campo
Exemplo: ...;F02312002001A;PC;47711;166268312215;10 → Ref F02312002001A · Qtd 10
Dados do Fornecedor
Configuração · Regex
Padrão da Referência
Regex para capturar a referência. Use grupo 1 (...) para o valor.
Ex: P([A-Z0-9]+) captura após "P"
Padrão da Quantidade
Regex para capturar a quantidade. Use grupo 1 para o número.
Ex: Q\d{3}(\d{3})\d{3} captura os 3 dígitos do meio de Q000010000
Aplicar transformação na quantidade (dividir por 10, 100...)
Configuração · Pipe / Separador
Formato: campo1;campo2;campo3...
Índice 0 = primeiro campo. Use -1 para o último campo, -2 para o penúltimo, etc.
Ex: 0000000000000;OP;...;F02312002001A;PC;47711;166268312215;10 → Ref índice 3, Qtd índice -1.
Configuração · Chave-Valor
Formato: CHAVE=valor;CHAVE2=valor2
Informe os nomes das chaves usadas neste fornecedor.
Configuração · Posicional
Extrai valores por posição fixa no texto do QR code.
Posições começam em 0. Início:Fim (fim exclusivo).

◆ OCR Vision — Referências Cadastradas
A câmera OCR (Google Cloud Vision) vai ler a etiqueta e identificar qual referência cadastrada está presente.
Qtd padrão é usada quando a etiqueta não tiver quantidade explícita.
Requer chave Vision API configurada no arquivo index.html.
Extração de Quantidade (opcional)
Se a etiqueta tiver a quantidade impressa, informe um regex para extraí-la.
Deixe em branco para sempre usar a qtd padrão cadastrada acima.
Ex: Qtd[:\s]*(\d+) · QTD=(\d+) · Q(\d{3,6})
